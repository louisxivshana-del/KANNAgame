# KANNA — 顔合体パズル　ゲーム構想書（v2）

> 旧構想「夜明けのランタン」は `docs/archive/CONCEPT_lantern.md` に保管。

## 1. 一言で言うと
**スイカゲーム型の落ちもの物理パズル。ピースは、自分で登録した写真から切り抜いた「顔」。**
同じレベルの顔同士がぶつかると合体してレベルアップし、ポイントを競う。

## 2. 基本ルール（確定）
| 項目 | 仕様 |
|---|---|
| 操作 | 落とすピースを左右に動かし、好きな位置で落とす |
| 落ちてくるピース | レベル 1・2・3 のいずれか（ランダム） |
| 合体条件 | **同じレベル同士が当たったときだけ**合体し、1つ上のレベルになる |
| 最大レベル | 8 |
| 消滅 | **レベル8同士が当たった瞬間**、両方とも消える |
| サイズ | レベルが上がるごとに大きくなる |
| 形 | レベルごとに異なる（＝登録した顔の輪郭の形） |
| 得点 | レベルアップ（合体）するたびに加算 |
| ゲームオーバー | ピースが上のラインを **3秒以上** 超え続けたら終了 |

## 3. ピースの見た目（顔ピース）
- **レベルごとに1枚ずつ写真を登録**する（最大8枚）。
  - 同じ人の写真を複数レベルに使っても、別の人でもよい。
- 写真から顔を**自動で切り抜き**、その**切り抜きがそのままピースになる**（輪郭＝形・当たり判定、顔画像＝見た目）。
- 切り抜きは**自分で調整できる**（輪郭の28個の点をドラッグして修正、枠全体の移動・拡大縮小、自動検出のやり直し）。
- 写真に複数の顔が写っている場合は、一番大きく写っている顔を切り抜く。
- 自動切り抜きは**頭単位**（髪＋顔の肌＋耳＋帽子などの小物。首から下は含めない）を**ピクセル単位**で切り抜く。iPhone の写真の「被写体を長押しで切り抜く」のイメージ。「顔だけ」で切り抜き直すこともできる。
- 枠の点は頭の外側に置かれ、内側に動かすとその部分が削れる。
- ゲーム中のピースは、切り抜いた輪郭に沿ってレベル色のふちを付ける（ステッカー風）。
- **写真が登録されていないレベル**は、**四角・丸・三角・しずく型**のどれかの形を**ランダム**で割り当てる。
  - 割り当てはゲーム開始時にレベルごとに決め、そのゲーム中は固定（同じレベルは同じ形）。
  - レベルごとに色を変え、**レベルの数字を表示**して区別できるようにする。
- **数字が書かれるのは写真なしピースだけ**。顔写真を登録したレベルのピースには数字を書かない（顔だけを見せる）。進化表（画面下のレベル一覧）でも同様。

## 4. 得点（案）
レベルが高い合体ほど高得点。

| 合体 | 得点 |
|---|---|
| Lv1+Lv1 → Lv2 | 1 |
| Lv2+Lv2 → Lv3 | 3 |
| Lv3+Lv3 → Lv4 | 6 |
| Lv4+Lv4 → Lv5 | 10 |
| Lv5+Lv5 → Lv6 | 15 |
| Lv6+Lv6 → Lv7 | 21 |
| Lv7+Lv7 → Lv8 | 28 |
| Lv8+Lv8 → 消滅 | 50（ボーナス） |

※ 数値は遊びながら調整する。

## 5. ランキング
- **完全オフライン**。端末内に保存（上位10件）。
- ランキングに入ったら**名前を入力して登録**する（10文字まで。前回の名前を自動で入れておく）。
- 同点の場合は先に出した記録を上位にする。
- 表示項目：順位・名前・得点・最高レベル・日付。

## 6. 画面構成
```
タイトル
 ├─ ゲームスタート ─→ プレイ画面 ─→ ゲームオーバー ─→（ランクイン時）名前入力 ─→ ランキング
 ├─ 顔ピース登録（Lv1〜Lv8 の写真登録・切り抜き調整）
 └─ ランキング
```
- **プレイ画面**: 箱（容器）、上のライン、次に落ちるピースの予告、現在の得点、レベル一覧（進化表）。
- **顔ピース登録**: 8つの枠。各枠で「写真を選ぶ → 自動切り抜き → 調整 → 保存」。

## 7. 方針：基本すべてオフライン
- 写真の読み込み・顔検出・切り抜きは**すべて端末の中**で行い、外部に送信しない。
- 登録した顔ピースとランキングは端末内（ブラウザのストレージ）に保存。
- 必要なライブラリやAIモデルもアプリに同梱し、ネットにつながっていなくても動くようにする。

## 8. 技術構成（実装はおまかせ）
| 役割 | 使うもの | 補足 |
|---|---|---|
| 画面 | HTML5 Canvas + JavaScript | ブラウザで開くだけで動く |
| 物理演算 | **Matter.js**（物理エンジン） | 落下・衝突・転がりを担当。衝突時に「同じレベルか」を判定して合体させる |
| 顔検出 | **MediaPipe Face Landmarker**（端末内で動くAI） | 顔の輪郭の点（フェイスライン）を取得 → ピースの形に |
| 保存 | IndexedDB（顔ピース画像・形） / localStorage（ランキング） | すべて端末内 |
| オフライン対応 | PWA（Service Worker） | 一度開けば以後オフラインで起動可能、ホーム画面に追加できる |

### 物理エンジンについて
- 物理エンジンの扱いは開発側で担当する。プレイヤーや企画側が使い方を知る必要はない。
- **ピースの形＝写真の切り抜きの形**。見た目だけでなく**当たり判定も切り抜いた輪郭そのまま**にする（丸や多角形で近似しない）。
  - 凹みのある形も、内部で複数の凸形状に分割して計算する（poly-decomp）。プレイヤーには切り抜きの形どおりに見え、そのとおりにぶつかる。
  - **軽さを重視**し、当たり判定の輪郭の点（接触点）は大きく間引く（目安：1ピース 12〜20 点）。見た目の画像は切り抜きのまま表示する。
- 各レベルのサイズは固定（例：Lv1 が最小、Lv8 が箱の幅の半分弱）。登録した顔はそのサイズに合わせて自動で拡大縮小する。
