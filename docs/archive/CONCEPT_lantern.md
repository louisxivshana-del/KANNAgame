# KANNA — 夜明けのランタン　ゲーム構想書

## 1. 一言で言うと
**「光が尽きる前に、闇を照らして生き延びる」** — ランタンを持つ少女カンナを操作し、
暗い森で蛍の光を集めながら、迫りくる影から逃げ延びるシングルスクリーン・アクション。

## 2. コンセプトの柱
| 柱 | 内容 |
|---|---|
| **光＝命＝時間** | ランタンの光は時間とともに弱まる。光の半径がそのまま「残り体力」であり「視界」。 |
| **リスクとリターン** | 光を消費して「光の爆発（バースト）」を放てば影を一掃できる。でも使いすぎると自分が闇に飲まれる。 |
| **すぐ遊べる** | ブラウザで開くだけ。PCはキーボード、スマホは指でドラッグ。1プレイ1〜3分。 |

## 3. ストーリー（最小限）
永い夜に包まれた森。灯守（ひもり）の少女・カンナは、最後のランタンを手に夜明けを待つ。
闇から生まれた「影」たちは光を喰らおうと彼女に群がる。蛍たちだけが味方だ。

## 4. ゲームループ
```
移動して蛍を集める → 光が回復・スコア加算
        ↓
影が寄ってくる → 逃げる or バーストで撃退（光を消費）
        ↓
時間経過で影が増える・速くなる → 光が尽きたらゲームオーバー
        ↓
スコア（生存時間＋蛍＋撃退数）を記録 → もう一回！
```

## 5. ルール詳細
- **光（ライト）**: 0〜100。毎秒少しずつ減る。0でゲームオーバー。
  - 画面は暗闇で、カンナの周囲だけ光の量に応じた半径で見える。
- **蛍**: ランダムに出現。取ると光 +12、スコア +10。
- **影**: 画面外から出現しカンナを追う。触れると光 −25（短い無敵時間あり）。
  - 光の内側に入ると少し遅くなる（光を嫌う）。
- **バースト**: スペース / ダブルタップ。光を 15 消費し、周囲の影を消し去る（1体 +25点）。
- **難易度**: 時間とともに影の出現間隔が縮み、移動速度が上がる。
- **スコア**: 生存秒数×1 ＋ 蛍 ＋ 撃退ボーナス。ハイスコアはブラウザに保存。

## 6. 操作
| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面をドラッグ（指の方向へ移動） |
| バースト | スペース | ダブルタップ |
| 開始 / リトライ | Enter / クリック | タップ |

## 7. ビジュアル・サウンド方針
- 暗い青紫の背景に、暖色のランタン光。光と闇のコントラストが主役。
- 素材ファイルは使わず、Canvasで図形・グラデーション描画（軽量・即起動）。
- 効果音は Web Audio API で簡易合成（蛍取得・被弾・バースト）。

## 8. 技術構成
- HTML5 Canvas + 素の JavaScript（ビルド不要、依存ライブラリなし）
- `index.html` を開くだけで動作。GitHub Pages でそのまま公開可能。
```
index.html      … 画面とキャンバス
src/game.js     … ゲーム本体（ループ・入力・描画・音）
docs/CONCEPT.md … この構想書
```
