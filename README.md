# KANNA — 顔合体パズル

スイカゲーム型の落ちもの物理パズル。同じレベルのピース同士がぶつかると合体してレベルアップ。
将来は、登録した写真から切り抜いた「顔」がピースになる（構想は [docs/CONCEPT.md](docs/CONCEPT.md)）。

## 遊び方
`index.html` をブラウザで開くだけ（ビルド・インストール・ネット接続 不要）。

| 操作 | PC | スマホ |
|---|---|---|
| 位置を決める | マウス移動 / ← → | 指でドラッグ |
| 落とす | クリック / スペース / ↓ | 指を離す |
| もう一度 | クリック / Enter | タップ |

- 落ちてくるのはレベル1〜3
- 同じレベル同士が当たると合体して1つ上のレベルに（Lv8同士は消える）
- 上の点線を3秒以上超え続けるとゲームオーバー

## 現在のバージョン：v0.1
- 写真なしピース（四角・丸・三角・しずく）。形はゲームごとにレベル別でランダム
- 合体・得点・Lv8消滅・3秒ゲームオーバー・ベストスコア保存
