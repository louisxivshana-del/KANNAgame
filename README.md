# KANNA — 夜明けのランタン

ランタンを持つ少女カンナを操作し、暗い森で蛍の光を集めながら影から逃げ延びるブラウザゲーム。

## 遊び方
`index.html` をブラウザで開くだけ（ビルド・インストール不要）。

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | ドラッグ |
| バースト（光を15消費して周囲の影を消す） | スペース | ダブルタップ |
| スタート / リトライ | Enter / クリック | タップ |

- 光は時間とともに減り、0になるとゲームオーバー
- 蛍を取ると光が回復、影に触れると光が大きく減る
- 時間が経つほど影は増え、速くなる

構想・ロードマップは [docs/CONCEPT.md](docs/CONCEPT.md) を参照。
