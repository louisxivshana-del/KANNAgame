# KANNA — 顔合体パズル

スイカゲーム型の落ちもの物理パズル。同じレベルのピース同士がぶつかると合体してレベルアップ。
レベルごとに写真を登録すると、切り抜いた「顔」の形と見た目のピースになる（構想は [docs/CONCEPT.md](docs/CONCEPT.md)）。

## 起動方法
ビルド・インストールは不要。

- **おすすめ：Webサーバーで公開して開く**（GitHub Pages など）
  - 一度開くと全ファイルが端末に保存され、以後は**ネットなしでも**起動・顔の自動切り抜きまで使える
  - スマホでは「ホーム画面に追加」するとアプリのように全画面で遊べる
  - パソコンで試すだけなら `python3 -m http.server 8000` → http://localhost:8000
- **`index.html` を直接開く**：ゲームとランキングはそのまま遊べる。
  ただしブラウザの制限で顔の**自動**切り抜きとオフライン保存は使えない（枠を手で顔に合わせて切り抜く）。

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 位置を決める | マウス移動 / ← → | 指でドラッグ |
| 落とす | クリック / スペース / ↓ | 指を離す |
| 一時停止 | Esc / P / 上の Ⅱ ボタン | 上の Ⅱ ボタン |
| 開始・もう一度 | ボタンをクリック | ボタンをタップ |

- 落ちてくるのはレベル1〜3
- 同じレベル同士が当たると合体して1つ上のレベルに（Lv8同士は消える）
- 上の点線を3秒以上超え続けるとゲームオーバー

## 現在のバージョン：v0.6
- 写真なしピース（四角・丸・三角・しずく）。形はゲームごとにレベル別でランダム。数字つき
- 顔ピース登録：Lv1〜8 に写真を登録 → **頭（髪・顔・耳）をピクセル単位で自動切り抜き**（iPhone の「被写体を切り抜く」のようなイメージ。顔だけ も選べる）→ 枠の点で削って調整。ピースには輪郭に沿ったレベル色のふち。切り抜きがそのままピースの形・当たり判定に（数字なし）
- 合体・得点・Lv8消滅・3秒ゲームオーバー
- オフラインランキング（上位10件・名前登録）
- 演出：合体でぽんっと膨らむ・波紋・高レベルで画面ゆれ、Lv8消滅は閃光と大きな文字、レベルに応じた合体音、スマホの振動
- 一時停止（アプリ切り替え時は自動で一時停止）、音のオン・オフ（保存される）
- オフライン対応（PWA）：ホーム画面に追加・ネットなしで全機能
- スマホ最適化：引っ張り更新・ダブルタップ拡大・長押しメニューを無効化

写真・ランキングはすべて端末内だけに保存され、外部には送信されない。

## 構成
```
index.html          画面（タイトル・リザルト・ランキングのパネル）
src/game.js         ゲーム本体
src/ranking.js      オフラインランキング（localStorage）
src/faces.js        顔ピース（写真登録・自動切り抜き・調整・保存）
src/screens.js      画面パネルの切り替え
src/style.css       パネルの見た目
sw.js               オフライン対応（Service Worker）
manifest.webmanifest / icons/  ホーム画面追加用の設定とアイコン
vendor/             同梱ライブラリ（Matter.js / poly-decomp / MediaPipe と顔認識モデル）→ vendor/README.md
docs/CONCEPT.md     構想書
```
